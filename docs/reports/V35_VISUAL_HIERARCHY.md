## 2. Visual Hierarchy Rules
1. **Never More Than One Primary:** At any given frame, only one visual event or element is permitted to carry maximum contrast and luminance.
2. **Directional Lighting Consistency:** All bevels, shadows, and edge highlights across all 5 beats must obey a consistent top-right key light source (-35° elevation, +45° azimuth).
3. **Restrained Emission:** Filaments emit light; brass reflects light; obsidian absorbs light; silica refracts light. No element is allowed to become an amorphous blob of uniform glow.
