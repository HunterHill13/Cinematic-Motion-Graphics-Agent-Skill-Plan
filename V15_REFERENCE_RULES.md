# V15 REFERENCE RULES & DIRECTOR-LED DESIGN MANDATES

## Core Axioms
> **"V14 = Content-Locked; V15 = Director-Led + Content-Locked."**
> **"ADD SHAPE, NOT WORD."**
> **"SELECT, DON'T RANDOMLY INVENT."**
> **"DIRECT, DON'T DECORATE."**

---

### MANDATE 1: SOURCE-AUTHORITY LOCK
The Agent has full authority over composition, geometry, lighting, rhythm, pacing, camera movement, and sound design. The Agent has **ZERO** authority to invent copy, names, numbers, or background words. Text is an immutable legal fact.

### MANDATE 2: LAYER BUDGET DISCIPLINE (THE 7-LAYER RULE)
Never activate all 7 layers at high visual intensity simultaneously.
- At any given frame, $\le 6$ layers may be active.
- There is only ONE hero graphic actor on screen at a time.
- Secondary motion (L5) must be causally tied to a primary event (L3/L4).

### MANDATE 3: SUBTLE BREATHING OVER STATIC STAGNATION
Static screenshots feel dead; frantic jitter feels cheap. Hero graphic actors must maintain an idle breathing micro-motion ($\pm 1.5\%$ scale @ $0.33\text{ Hz}$) once settled.

### MANDATE 4: ONE CONTINUOUS PERFORMANCE (ONETAKE CONTINUITY)
Transitions between shots are physical state changes of persistent carrier objects. Never use generic full-frame wipes or crossfades.
- T1: Baseline ray $\to$ Upper monolith rule
- T2: Decree medallion $\to$ Triad prerequisite columns
- T3: Horizontal datum $\to$ 12-month calendar ruler
- T4: Calendar axis $\to$ Architectural floor plinth
- T5: Score plinths $\to$ Heraldic institutional crest

### MANDATE 5: ACOUSTIC-VISUAL CO-ANCHORING
Every major visual impact (keyword strike, seal collision, pedestal strike) is precisely anchored to a voice milestone ($\Delta = 0\text{ frames}$) and paired with a -16dB to -14dB SFX marker.

### MANDATE 6: CLEAN PERSIAN ORTHOGRAPHY IN DISPLAY
Display typography must adhere to standard formal Iranian print standards. Arabic vowels (fatha, damma, kasra, tashdid) added solely for TTS engines must NEVER contaminate `displayText`.
