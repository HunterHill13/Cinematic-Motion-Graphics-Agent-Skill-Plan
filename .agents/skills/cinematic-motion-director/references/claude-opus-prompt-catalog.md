# Claude Opus 5.5 Viral Prompt Catalog

A curated collection of verified prompt patterns reverse-engineered from 500+ viral motion graphics videos:

## 1. The Legendary Showreel Persona Trigger
```text
Make a dynamic 15-second motion graphics video that shows what an incredible motion designer you are, like it's your showreel for a résumé. Go all out.
```
**Mechanism:**
- Bypasses conservative default LLM styling.
- Forces high element density, layered volumetric lighting, multi-step choreographies, and energetic spring physics.

## 2. The Dribbble-Grade Morphing UI Prompt
```text
<direction>
Dribbble-level UI motion. One shape, never cut: every state is the same element morphing its size, radius and color while its content swaps with a short blur. A cursor drives every change with real clicks and drags. Light warm-gray or deep-slate canvas, black and white components, one clean UI font. Springs everywhere, a tiny overshoot at most.
Banned: bouncy easing, particle bursts, glows, gradients on UI chrome, mismatched icon strokes, dead time.
</direction>
<structure>
120 BPM, 7 bars, something happens on every beat:
Button → loader → check → dynamic island → music player with scrub → volume slider → liquid tab indicator → chart that draws itself with tooltip on hover → command palette filter → toast.
</structure>
```
