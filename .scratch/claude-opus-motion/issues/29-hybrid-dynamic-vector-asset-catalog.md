# Ticket 29: Hybrid Dynamic Vector Asset Catalog & Engine

## Objective
Build a comprehensive procedural mathematical vector catalog (`src/motion/library/DynamicVectorCatalog.ts`) and universal morphing card (`src/motion/recipes/UniversalVectorMorphCard.tsx`) containing high-precision normalized vector geometries across 6 core scientific and technical domains.

## Requirements
1. Define standardized SVG vector path blueprints normalized to 200x200 viewBox:
   - `NEURAL_SYNAPSE` (AI / Neural Networks / Synaptic nodes)
   - `DNA_HELIX_ORBIT` (Biomedical / Genetics / Cellular Helix)
   - `QUANTUM_ORBITALS` (Physics / Computing / Atomic Shells)
   - `EXPONENTIAL_CHART` (Fintech / Growth / Vector Metrics)
   - `SECURITY_SHIELD` (Cybersecurity / Cryptography / Defense)
   - `STELLAR_OCTAGRAM` (Cosmic / Core / Standard)
2. Support Flubber / Normalized Spline path interpolation between ANY pair of domains with 0 topological glitches.
3. Universal Card component adapting to Glassmorphic, Paper Cutout, Technical Blueprint, and Neo-Brutalist themes.
