# Band Kaf Official Script & Dual-Representation Specification

## 1. Phonetic Spoken Script (SpeechText)
Used exclusively as input to the Google Gemini Multimodal Audio API (`gemini-2.5-flash-preview-tts` / `Puck`).
Preserves exact Arabic/Persian diacritical marks (harakat/tashdid) required for pristine phonetic pronunciation.

```text
«روابطِ عمومیِ کُمیته‌یِ تَحقیقاتِ دانشگاهِ عُلومِ پِزِشکیِ بَقیَّتُ‌الله (عَج) تَقدیم می‌کُند:
بَندِ «کاف»؛ مُهِم‌ترین مَسیِرِ ورود به عُنوانِ پِژوهِشگَرِ بَرجَستِه‌یِ کشوری.
این بَند شامِلِ سِه مادّه‌یِ اَصلی اَست:
مادّه‌یِ یک: مُعَدَّل و آزمون‌هایِ جامِع.
مادّه‌یِ دو: پیشینِه‌یِ پاکِ انضباطی.
و مادّه‌یِ سِه: حَداقَل شِش مقالِه‌یِ پژوهِشی.
تَوجُّه: تَاییدیهیِ کُمیته‌یِ تحقیقات، شرطِ لازم برایِ بَررِسی اَست.
حِسابِ اِمتیازاتِ شُما، گامبِهگام در سامانِه‌یِ پِژوهِشی ثَبت خواهَد شُد.
کَفِ اِمتیازات برایِ دورِه‌هایِ مُختَلِف: کارشناسی شَصت و پَنج، کارشناسیِ ارشَد صَد و دَه، و دُکتریِ حِرفِه‌ای صَد و سی اِمتیاز اَست.
هَم‌اَکنون فُرصَتِ طَلایی برایِ اقدام فَراهَم اَست.
برایِ شُروع، به وب‌سایتِ کُمیته‌یِ تَحقیقات مُراجِعه فَرماِیید.»
```

## 2. Sanitized Visual Script (DisplayText)
Used on screen in motion graphics and kinetic typography. Stripped of diacritics with normalized institutional typography.

```text
روابط عمومی کمیته‌ی تحقیقات دانشگاه علوم پزشکی بقیه‌الله (عج) تقدیم می‌کند:
بند «کاف»؛ مهم‌ترین مسیر ورود به عنوان پژوهشگر برجسته‌ی کشوری.
این بند شامل سه ماده‌ی اصلی است:
ماده‌ی یک: معدل و آزمون‌های جامع.
ماده‌ی دو: پیشینه‌ی پاک انضباطی.
و ماده‌ی سه: حداقل شش مقاله‌ی پژوهشی.
توجه: تأییدیه‌ی کمیته‌ی تحقیقات، شرط لازم برای بررسی است.
حساب امتیازات شما، گام‌به‌گام در سامانه‌ی پژوهشی ثبت خواهد شد.
کف امتیازات برای دوره‌های مختلف: کارشناسی ۶۵، کارشناسی ارشد ۱۱۰، و دکتری حرفه‌ای ۱۳۰ امتیاز است.
هم‌اکنون فرصت طلایی برای اقدام فراهم است.
برای شروع، به وب‌سایت کمیته‌ی تحقیقات مراجعه فرمایید.
```
